# asset_vault (gitignored)

Rebuilt by `python bootstrap_studio.py`:

- `hdri/`: Poly Haven CC0 HDRIs (studio_small_09, golden_bay), 2k
- `textures/`: generated face atlases, per-character detail layers, torso prints, screens and posters
- `ldraw/`: official LDraw parts library (only with `--with-ldraw`)
- `downloads/`: cached archives
- `lookdev/`: scratch renders from `tools/lookdev_test.py` / `tools/set_preview.py`
